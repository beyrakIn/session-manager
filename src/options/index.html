Password protection and auto-lock

Password protection

Sessions are stored unencrypted today. Turning this on encrypts every saved session with a password you choose, using AES-GCM with a key derived from that password. The key is never written to disk.

There is no recovery. If you forget the password, every saved session is permanently unreadable.
